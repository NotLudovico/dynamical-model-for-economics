# relative-glv

A scale-invariant generalised Lotka-Volterra model of interacting firms on a scale-free network,
and the theory of what it predicts for firm-growth statistics.

**Start here:**
- [`docs/STORY.md`](docs/STORY.md): the question, the model, the theory, the results against the
  Moran-Secchi-Bouchaud (2024) facts, the limits, and where each piece of code lives.
- [`docs/CEMETERY.md`](docs/CEMETERY.md): every model and protocol that was tried and abandoned, and why.

The main model adds birth-death noise and firm turnover to the relative GLV,

$$dx_i = x_i\left[1 - \frac{x_i}{m} + \frac{(Wx)_i}{m}\right]dt + \sqrt{D\,m\,x_i}\,dW_i,\qquad m = \langle x\rangle,$$

with a newborn of size $Dm$ replacing every firm that reaches zero. It reproduces $\beta = 0.20$ and
the multiscaling spectrum $\zeta_q$ of Compustat over two decades, with a derived mechanism for the
multiscaling (the degree distribution of the network), but not Zipf's law or a four-decade range.

The sections below describe the package and the thesis-era code.

## Layout

```
relative_glv/        the package: model (integrate, integrate_demographic, coupling,
                     configuration_coupling), msb (firm-growth estimators, life panel),
                     dmft / hdmft / renewal (mean-field theory)
tests/               unit and validation tests (uv run pytest)
scripts/
  demographic/       main model: MSB facts, robustness, multiscaling mechanism
  phase/             phase diagram of the deterministic model
  lifecycle/         exact one-firm theory (deterministic limit)
  thesis/            generators of the submitted thesis figures (map: thesis/FIGURES.md)
docs/
  STORY.md           what the project claims, results, limits, where things are
  CEMETERY.md        everything tried and abandoned, and why
  dmft-derivation.md DMFT self-consistency derivation
thesis/              the submitted thesis, standalone notes and the paper draft (thesis/standalone/paper/)
data/                outputs (large ones gitignored, regenerable); data/logs/ holds printed results
```

See [`scripts/README.md`](scripts/README.md) for what each script does.

## Install and run

```bash
uv sync --extra dev          # package and dev dependencies
uv run pytest                # tests
uv run python scripts/demographic/robustness.py summary   # e.g. reprint the robustness results
```

The thesis figures are regenerated by the scripts listed in [`thesis/FIGURES.md`](thesis/FIGURES.md).

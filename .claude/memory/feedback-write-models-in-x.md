User (2026-10-11): "dont talk to me in terms of S, i need to see the model in x to understand what's going on".

**Why:** the relative-size form d lnS = Phi - S hides where each term acts (e.g. the self-limitation x_i/m and the plateau x* = m Phi), so the user can't follow the mechanism.
**How to apply:** write every proposed model as x_i' = x_i[...] with m = <x>, and explain mechanisms (fixed points, brakes, normalisation) in x. Relative sizes x/m are fine as an output/observable (size bins, Zipf), not as the model statement. Related: [[project-scope-model]].

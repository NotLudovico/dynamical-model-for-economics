User (2026-10-11), after I proposed markets (thesis GLV) + shares (Reed) + firm portfolios with 7–8 parameters: "this model is too complicated".

**Why:** it's a mechanism paper; each extra layer or parameter reads as fitting, and the user wants theory on a simple model. Earlier they also objected to "too many new ingredients".
**How to apply:** before proposing a model, count layers and parameters against the thesis model (mu, sigma, lambda, alpha, C). Prefer one-layer modifications. When a fact seems to need a new layer, say so and present it as a trade-off or a limitation instead of stacking ingredients. Related: [[feedback-minimal-parameters]], [[project-scope-model]].
